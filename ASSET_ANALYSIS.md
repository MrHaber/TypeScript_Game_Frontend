# Анализ и разделение SVG-ассетов

Исходные SVG-паки лежат в `assets/`. Они экспортированы как большие листы с множеством отдельных контуров без явных групп на каждый объект, поэтому ассеты разделяются автоматически по геометрическим кластерам.

Генератор: `tools/extract_svg_assets.py`.

Результат: `assets/Разделенные ассеты/`.

## Категории

| Категория | Количество SVG |
| --- | ---: |
| `Иконки` | 50 |
| `Стиль Английский` | 43 |
| `Стиль Музыка` | 41 |
| `Стиль Учи.ру_завры` | 41 |
| `Стиль Учи.ру_люди` | 39 |
| `Стиль Чумовая ферма` | 31 |

Всего сгенерировано 245 отдельных SVG. Файлы названы предметно: например `улыбающийся_смайлик.svg`, `вишня.svg`, `кошелек.svg`, `класс_английского.svg`, `девочка_на_пляже.svg`, `горшок_меда.svg`.

Для стилевых паков включен второй проход разделения по крупным внутренним якорям. Он нужен для случаев, когда один исходный кластер содержит несколько карточек, персонажей или локаций на одном листе.

## Прозрачный фон

Большой белый фон исходного листа определяется по площади и не переносится в отдельные SVG. Белые детали самих объектов, например глаза, блики, зубы и текстуры, остаются нетронутыми.

## Служебные элементы

Маленькие верхние ярлыки листов вроде названия категории отфильтрованы и не попадают в набор ассетов.

Подробный список файлов, названий и `viewBox` для каждого ассета лежит в `assets/Разделенные ассеты/manifest.json`.
